# Experiments sheet

Generated by `results/make_experiments.py` from `results/*.csv` (built from `results/ledger.csv`). Do not edit by hand.

**Protocol (all K-Fold results):** 5 folds × 3 repeats = 15 outer folds, identical for every model, so every comparison is paired. Library models: Optuna TPE, 30 trials (Stacking 10), 3 inner folds. Neural nets: epoch count (and classify threshold) chosen on 3 inner folds. Main metric F1 (classify) / R² (regression). Tests: Nadeau–Bengio corrected resampled t (main, conservative), Wilcoxon (optimistic), bootstrap 95% CI.

## Things to keep in mind

- Tuning uses 3 inner folds instead of 5.
- The interaction EDA used all rows, so any V5 gain is slightly optimistic.
- Picking the best of several variants on the same folds favours the variants; the plain baselines are in the gate tables too.
- Scratch twins take epochs and threshold from the pytorch twin; they are 1-repeat parity checks, not contenders.
- The old FT and NAM numbers chose their best epoch on the test set (V2); they are excluded from every comparison here.
- FT classification with the identical 22 features scores differently in V4_1 and V5_1 (dropout random stream differs); treat differences of about 0.01 F1 as noise.
