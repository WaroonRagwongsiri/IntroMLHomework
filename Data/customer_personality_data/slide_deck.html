04 Foundation

Cleaning Applied

Five changes, applied to both tracks before any analysis — none of them touch Response or Income directly.

  • 01 Drop ID — identifier, not a feature
  • 02 Drop Z_CostContact / Z_Revenue — constant columns
  • 03 Parse Dt_Customer → derive Customer_Tenure_Days A raw date string has no numeric meaning on its own. Re-expressed as days since enrollment, relative to the dataset's latest signup (2014-06-29) — a usable behavioral signal instead.
  • 04 Derive Age from Year_Birth — 3 outlier rows (121/115/114 yo) dropped Birth years 1893/1899/1900 are almost certainly data-entry errors, not real ages. Only 3 of 2,240 rows — too few to impute credibly, so dropped outright.
  • 05 Collapse Marital_Status joke categories (Absurd/YOLO/Alone → Single) Absurd/YOLO (2 rows each) read as placeholder joke entries; Alone (3 rows) means the same thing as Single. All three too small to analyze as their own category.

06 Classification

Relevance Score — How It's Computed

Two methods, split by feature type — both scored against Response (0/1), both judged against the same 0.10 threshold so the results sit on one ranked chart.

Point-biserial correlation

For the 16 numeric candidates. Codes Response as 0/1 and correlates it directly — the formula is Pearson r, not just "like" it. Why: it's the standard linear-association measure for numeric-vs-binary, and its sign shows which class a feature leans toward.

r_pb  =  ((M_1 − M_0) / s_n)  ·  √(n_1·n_0 / n²)

M₁, M₀ = feature mean where Response = 1 / 0 · s_n = feature's std · n₁, n₀, n = group / total sizes

Cramér's V

For the 2 nominal candidates (Education, Marital_Status) — categories have no numeric order, so Pearson can't apply. Why: a chi-square test of independence on the contingency table, rescaled to a bounded 0–1 score.

V  =  √( χ² / (n · min(k−1, r−1)) )

χ² = chi-square statistic on the contingency table · n = rows · k, r = table columns / rows

Threshold |score| ≥ 0.10 to be considered relevant.

11 Classification

Cross-Check — Mutual Information

What it is

An information-theoretic measure: how much knowing a feature's value reduces uncertainty about Response. Unlike Pearson/point-biserial, it isn't limited to linear relationships — it catches any statistical dependency, monotonic or not.

mutual_info_classif · range 0 → ∞, no fixed upper bound · 0 = independent

Why run a third method

Point-biserial only sees linear signal; RF importance depends on how trees happen to split — greedy, order-sensitive, distorted by multicollinearity. MI asks a cleaner question: is there any dependency at all, regardless of shape? Agreement across all three is a stronger claim than any one method alone.

16 Regression

Relevance Score — How It's Computed

Same split-by-feature-type logic as the classification track — but note: the two formulas below are not the same math, just parallel roles.

Pearson |r|

For the 22 numeric candidates vs. Income. Why: both sides are continuous, so the direct covariance-based linear-association measure applies — no special case needed.

r  =  Σ(x_i−x̄)(y_i−ȳ) / √( Σ(x_i−x̄)² · Σ(y_i−ȳ)² )

x̄, ȳ = feature / Income means · x_i, y_i = per-row values · reported as |r|

Correlation ratio η

Education / Marital_Status vs. Income. Why: nominal categories again rule out Pearson — this is an ANOVA-style ratio of between-group to total variance, unsigned since group order carries no meaning.

η  =  √( Σ_g n_g(ȳ_g−ȳ)² / Σ_i(y_i−ȳ)² )

g = a category group · n_g, ȳ_g = that group's size / mean Income · ȳ = overall mean

Not the same formula Pearson r and correlation ratio η play parallel roles (categorical analogue) but compute different things — η is a variance-explained ratio (0 to 1, unsigned), while r is a signed linear-slope measure (−1 to +1). Same threshold, different math.

Small-n caveat — and how we handled it With only ~2,200 rows, any single method's ranking is noisier than on a larger dataset — a method-specific quirk can look like real signal. That's exactly why "chosen features" above means agreement across all three independent methods, not one score: a ranking that survives three different statistical assumptions is far less likely to be a small-sample fluke than any one method's top pick alone.
